# Harddisk-Haiku-overlay

![Harddisk Haiku overlay](https://beosmeanwhilehaiku.wordpress.com/wp-content/uploads/2026/09/haikuhd.png)

'Harddisk Haiku.hvif' is a combined icon to identify a mounted Haiku partition/HD, in addition to the already existing 'Be' and 'Zeta' varieties. 'Haiku overlay.hvif' is the overlay itself.
